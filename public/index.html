    Ringkasan Naskah (Abstract Preview)

    Abstrak: Bencana kebakaran hutan dan lahan (karhutla) tahunan di Kalimantan menimbulkan dampak ekologis dan kabut asap pekat. Penelitian ini mengembangkan model kecerdasan buatan untuk mengklasifikasikan titik panas satelit NASA FIRMS (sensor MODIS C6.1 NRT periode Agustus–Oktober 2026, total 24.414 observasi Kalimantan) ke dalam kategori DARURAT (Prioritas Pemadaman) dan AMAN (Terkendali) menggunakan algoritma Gaussian Naive Bayes.

    Fitur masukan meliputi koordinat geografis (latitude, longitude), temperatur kecerahan api (brightness), dan keyakinan deteksi (confidence). Hasil evaluasi menunjukkan model Gaussian Naive Bayes memiliki sensitivitas dan akurasi tinggi serta beban komputasi sangat ringan, menjadikannya ideal untuk diimplementasikan pada arsitektur web serverless real-time bagi Satgas Pemadaman Karhutla di lapangan.
